Python by Example Python 3.14 — loads on first Run

Every runnable example executes CPython 3.14.2 compiled to WebAssembly (Pyodide) — the same interpreter you'd install, running entirely in your browser. Nothing is sent to a server; the one-time ~10 MB runtime download comes from the jsDelivr CDN.

Content targets modern Python (3.12+ baseline). Features newer than that are flagged with a new badge. Blocks marked reference show real-world code that needs packages or network access and can't run in the browser sandbox — read them, copy them, run them locally.

⌘/Ctrl + Enter runs the example under your cursor · Tab indents · All examples share one persistent interpreter (notebook-style) — reload the page to reset it.
